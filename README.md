# Java ShareIt — Item Sharing Service

## Tech stack
- Java 21
- Spring Boot
- Spring Data JPA (Hibernate)
- PostgreSQL
- Maven

## Description
This project implements a backend service that allows users to share items, create bookings, and manage requests.  
It demonstrates REST API design, business logic, and ORM integration using Hibernate.

## Features
- CRUD operations for items, bookings, and requests  
- Booking and availability management  
- User roles and permissions  
- Data validation and error handling  
- Persistent storage with Hibernate and relational database
